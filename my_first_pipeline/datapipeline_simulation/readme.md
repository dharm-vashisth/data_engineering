# Data pipeline simulation
Modular data pipeline using medallion(silver reinforcement) architecture.

## Description:
Reading the file name using command line. fetching raw data using polars and then storing it in duckdb.

## Tech stack
- polars (for processing)
- duckdb (for storage)
- logging (for tracking)

usage : `datapipeline_automation/processor.py --file raw_data.csv`
